Plugin Connect (QGIS 3)

Navegação ágil e inteligente entre grupos de camadas.

O que é o Connect?

O Connect é um plugin desenvolvido nativamente para QGIS 3 focado em produtividade. Ele foi criado para resolver um problema clássico de quem trabalha com projetos complexos: a perda de tempo ativando e desativando camadas manualmente para comparar cenários.

🚀 Principais Funcionalidades:

  • Integração Nativa: Adicione grupos ao painel diretamente pelo menu de contexto (botão direito).
  • Navegação Fluida: Use as setas do teclado (↑ e ↓) para alternar cenários. O plugin oculta o grupo atual e ativa o próximo automaticamente.
  • Organização Inteligente: Reordene itens por drag-and-drop e salve todo o estado direto no arquivo do projeto (.qgz).
  • Atalho Rápido: Pressione F9 para abrir/fechar o painel instantaneamente.
