## 🛠️ Desenvolvimento de Ferramentas (GIS)

### 2. Plugin Connect (Solução para QGIS 3)
Criação de um plugin nativo para QGIS que otimiza a rotina de quem trabalha com projetos cartográficos complexos. 

* **Funcionalidade:** Permite a navegação ágil entre grupos de camadas na árvore do QGIS (ativando/desativando visualizações rapidamente com teclas de atalho).
* **Tecnologias:** Python, PyQGIS.
* 📁 **[Ver Códigos do Plugin](./Connect_GIS)**
